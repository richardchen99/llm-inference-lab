# Documentation figures

All screenshots are captures of the running [LLM Inference Lab](https://richardchen99.github.io/llm-inference-lab/) using public built-in examples. They show application content only and are also used in the [project research note](https://richardchen99.github.io/blog/llm-inference-lab-note/). Capture date: **2026-09-18**.

| File | Captured state |
| --- | --- |
| [`overview.jpg`](overview.jpg) | Sentence example; first continuation token `on`; both layers completed; zero displayed cache/full-prefix error |
| [`memory.jpg`](memory.jpg) | 32 layers, 8 KV heads, head dimension 128, context 4,096, BF16, batch 1; K/V tensors total 512 MiB |
| [`families.jpg`](families.jpg) | Encoder–Decoder; target Query 2 and source cross-attention |

[`architecture.svg`](architecture.svg) is an original, editable vector schematic prepared for this repository. [`architecture.png`](architecture.png) is its 3,200-pixel-wide raster export. It separates the two-layer numerical model, independent equivalence check, and larger memory-budget configuration; see the [README](../../README.md#mathematical-scope).

No screenshot is a synthetic interface image. The framework diagram is drawn with vector shapes and text, not generated by a text-to-image model. Figures contain no editor windows, browser chrome, local paths, or private account details. Numerical values illustrate the stated experiment and are not performance benchmarks.
